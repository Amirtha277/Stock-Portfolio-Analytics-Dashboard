📊 Stock Portfolio Analytics Dashboard
Overview

The Stock Portfolio Analytics Dashboard is an interactive Business Intelligence solution developed using Power BI and MySQL to analyze stock investments, portfolio performance, profitability, and transaction trends.
This project helps users track investments, evaluate profits and losses, monitor stock performance, and make informed investment decisions through interactive dashboards and visual analytics.
