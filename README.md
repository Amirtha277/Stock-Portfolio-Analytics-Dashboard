📊 Stock Portfolio Analytics Dashboard

The Stock Portfolio Analytics Dashboard is a Business Intelligence project developed using Power BI and MySQL to analyze stock investments, portfolio performance, profitability, and transaction trends. The project utilizes a relational database consisting of Users, Stocks, Transactions, and Market Data tables, with relationships established through primary and foreign keys. SQL was used for database creation, data generation, and analytical query execution, while Power BI was used to transform and visualize the data through interactive dashboards.

The dashboard provides comprehensive insights into investment performance through features such as Total Investment Tracking, Profit Analysis, Profit Percentage Calculation, Company-wise Performance Comparison, User-wise Profit Analysis, and Buy/Sell Recommendations. Additional transaction analytics include average buy and sell prices, total transaction volume, quantity analysis, investment trends over time, and company-wise investment distribution. SQL queries were used to perform profit and loss calculations, risk classification, price change analysis, and recommendation generation.

Through this project, I gained practical experience in SQL query writing, database design, data modeling, Power BI dashboard development, DAX calculations, Power Query transformations, and business intelligence reporting. The project strengthened my ability to transform raw financial data into meaningful insights and create data-driven visualizations for investment analysis and decision-making.
